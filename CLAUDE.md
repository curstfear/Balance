# Balance — памятка для работы

Фитнес-PWA под iPhone уровня полноценного продукта. Пользуются владелец и его знакомые:
каждый на своём телефоне, со своими данными. Сервера нет, данные хранятся только на устройстве
(IndexedDB). Хостинг — GitHub Pages. Язык интерфейса — русский (тексты вынесены, чтобы потом добавить другие).

## Главное
Кор-фича — **автоматически собранная тренировка**: пришёл в зал → «Начать тренировку» →
приложение по телу, целям, тренажёрам зала и истории собирает сессию и ведёт её вживую.
В следующий раз (через день или через месяц) смотрит, какие мышцы и как нагружались,
и собирает новую так, чтобы тело развивалось равномерно и был прогресс.

## Запуск
- `npm i` → `npm run dev` (локально, `--host` — открыть с iPhone по Wi-Fi), `npm run build` — tsc + сборка в `dist/`.
- Деплой: пуш в `main` → GitHub Actions ([.github/workflows/pages.yml](.github/workflows/pages.yml)) → https://curstfear.github.io/Balance/
- Стек: Svelte 5 + TypeScript 6 + Vite. `npm run check` — svelte-check.
- `src/ui/screens/` — экраны, `src/ui/components/` — компоненты, `src/ui/nav.svelte.ts` — стек экранов
  (push / modal / жест «назад»), `src/ui/strings.ts` — все тексты, `src/styles/tokens.css` — токены.
- Сейчас — превью: «Сегодня» → план → подход → отдых → итог. Данные — заглушки в `src/preview-data.ts`.
- Дизайн: flat, без бликов и «реалистичных» градиентов; свечение — только на карточках-героях с иллюстрацией.
- Тексты интерфейса — официальный нейтральный стиль, без разговорных слов («норм» и т. п.). Правила — docs/roadmap.md.
- Порядок работ и признаки готовности — [docs/roadmap.md](docs/roadmap.md).

## Правила
- Движок тренировок — **чистые функции без UI и IndexedDB**, покрыт тестами из docs/engine/test-scenarios.md.
  Правило меняется сначала в docs/engine/, потом в коде.
- Все числа (объёмы, отдых, шаги прогрессии, пороги) — в одном конфиге движка, зеркало docs/engine/config.md.
- Жёсткие лимиты безопасности проверяются финальным проходом по каждой собранной сессии; при нарушении — урезать, не пропускать.
- Каждое решение движка объяснимо: у упражнения в тренировке есть короткое «почему».
- Хранится сырой факт (подходы, вес, повторы, RIR). Состояние мышц, рекорды, объёмы — вычисляются.
- Схема БД версионируется, миграции не теряют историю. Данные пользователя никогда не удаляются молча.
- Приложением пользуются чужие люди: никаких захардкоженных данных владельца, никаких отладочных
  экранов в проде, понятные пустые состояния и ошибки, ничего не ломается без интернета.
- Проверять на iPhone (Safari и ярлык «На экран Домой»), не только в Chrome.
- Это не медицинский совет: при болях и травмах приложение исключает упражнения, а не «лечит».
