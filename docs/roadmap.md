# План и открытые вопросы

## Технологии (предложение, утвердить перед кодом)
- Vite + TypeScript (strict).
- UI: Svelte или Preact — лёгкие, быстрые на iPhone. (React — если важнее экосистема.)
- Dexie (IndexedDB), vite-plugin-pwa (офлайн, обновления), Vitest (движок), Playwright с WebKit (сценарии).
- Деплой: GitHub Actions → GitHub Pages (учесть базовый путь `/Balance/`).
- Структура: `src/engine` (чистая логика, без UI), `src/data` (БД, каталог), `src/ui` (экраны), `docs/`.

## Этапы

**0. Фундамент** — проект, PWA-манифест и иконки, офлайн, деплой, дизайн-система (цвета, шрифты,
компоненты), каркас навигации. Проверка установки на iPhone.

**1. Каталог** — мышцы, оборудование, 100–150 упражнений с разметкой (паттерн, вклад, противопоказания, замены).
Это фундамент качества тренировок — делаем аккуратно.

**2. Движок v1** — сборка тренировки, прогрессия, восстановление, возврат после перерыва. Только логика + тесты
по сценариям из training-engine.md.

**3. MVP-интерфейс** — онбординг, «Мой зал», главная, превью, режим тренировки (таймер, ввод подхода,
замена), итог, история. → **Первый реальный тест в зале** (сначала владелец, потом 2–3 знакомых).

**4. Прогресс** — карта мышц, графики по упражнениям, рекорды, замеры тела.

**5. Надёжность** — бэкап/импорт, миграции, подсказка установки, полировка состояний и анимаций.

**6. Мезоциклы и разгрузки**, баланс тела, тонкая настройка движка по реальным данным.

**Позже** — питание, сон, фото прогресса, кардио.

## Критерии «MVP готов»
- Новый человек без объяснений проходит онбординг и первую тренировку.
- 4 недели реальных тренировок: веса растут, мышцы покрыты равномерно, нет абсурдных тренировок.
- Ничего не теряется при закрытии приложения, перезагрузке телефона, обновлении приложения.
- Работает в зале без интернета.

## Решено
- Техника упражнений — картинка + 2–3 подсказки, **без видео**.
- Синхронизации между устройствами **не будет** (только бэкап/импорт).
- Перед кодом — мокапы ключевых экранов, без спешки.
- Каталог упражнений: черновик готовит Claude, владелец проверяет.

- Мужские и женские программы отличаются только приоритетами по умолчанию, микрошагами веса и отдыхом
  (см. engine/load-and-progression.md §9).
