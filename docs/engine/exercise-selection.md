# Подбор упражнений и сборка сессии

Как из каталога, зала, истории и состояния мышц получается конкретная тренировка.
Объёмы, веса и повторы — в [load-and-progression.md](load-and-progression.md); запреты — в [safety.md](safety.md).

## 1. Схема упражнения
```ts
Exercise {
  id, name: {ru, en}, aliases[]
  equipment: EquipId[][]      // И из ИЛИ: [["bench_flat","bench_adj"],["dumbbells"]]
  equipClass: barbell | dumbbell | cable | machine_stack | machine_plate | smith | bodyweight | band | kettlebell
  station: StationId          // "cable_tower","rack","db_area","leg_press"… — для «занято» и суперсетов
  pattern: Pattern            // см. catalog.md
  vectorKey: string           // ключ избыточности: "vpull_pronated_wide" — два одинаковых не в одной сессии
  mechanics: compound | isolation
  laterality: bilateral | unilateral | alternating
  muscles: {MuscleId: 1 | 0.75 | 0.5 | 0.25}
  lengthBias: long | mid | short   // где пиковая нагрузка на главную мышцу
  lengthenedPartialsOk: bool       // полуамплитуда в растяжении (только опытным)
  stability: 1 | 2 | 3             // 1 тренажёр/опора, 2 блок/гантели с опорой, 3 свободно стоя
  skill: 1 | 2 | 3
  fatigue: 1 | 2 | 3
  axial: none | low | moderate | high
  needsSafety: bool                // штанга: жим лёжа, присед — нужна рама/упоры
  gripLimited: bool
  load: external | bodyweight | bodyweight_plus | assisted
  setupSec: number                 // по умолч. из equipClass: тренажёр 45, блок 45, гантели 60, штанга 120
  supersetOk: bool                 // false при axial ≥ moderate или skill 3 (§7)
  repRange?: {strength, hyper}     // переопределение
  minExperience: novice | intermediate | advanced
  contraindications: [{zone, level: avoid | modify}]
  transferGroup: string            // для коэффициентов перехода веса между упражнениями
  weightStep?: number | null       // кг; по умолч. из equipClass (catalog.md «Шаг веса»), null — прогрессия повторами
  technique: {art?: {id, first}, cues[2–3]}   // art — рисунок Everkinetic (начало/конец), см. catalog.md «Изображения»
  custom: bool, dataSource: curated | user | inferred
}
```

## 2. Алгоритм `buildSession(ctx)`
Вход: профиль, зал, история, чек-ин, время. Всё ниже — чистые функции.

```
rng  = seeded(hash(profileId, date, workoutCount))    // только для тай-брейков

// 0. Допуск и контекст (safety.md, load-and-progression.md)
if blocked(ctx) → нет сессии, экран с причиной
mode = {novice, cautious, teen, age50, age65, returnRow, deload, mesoWeek}

// 1. Пул
pool = (catalog ∪ custom).filter(
  equipOK(gym, busy) ∧ safetyOK(zones, age, pregnancy…) ∧ skill ≤ maxSkill(mode)
  ∧ (needsSafety → gym.safetyPins) ∧ pref(e) > −∞ ∧ dataSource ≠ "user-без-мышц")

// 2. Потребность мышц
reach[m] = ∃ e ∈ pool: e.muscles[m] ≥ 0.5            // недостижимые мышцы не копят долг
need[m]  = clamp(target[m] − done7d[m] + debt[m], 0, 1.5·target[m]) · prio[m] · readyF(m)
           // readyF: R ≥ 0.8 → 1; 0.5–0.8 → 0.5 и только изоляция; < 0.5 → 0
need[m] *= balanceBoost(m)                              // 30 дней: тяни/толкай < 1, бицепс бедра/квадр < ⅔,
                                                        // задняя/передняя дельта < ½ → ×1.2–1.4

// 3. Фокус
focus = argmax_T Σ_m need[m]·cover(T, m) − 0.3·[T совпадает с двумя последними типами]
        // T ∈ типы шаблона частоты: Full / Upper / Lower / Push / Pull / Legs

// 4. Слоты
slots = slotPlan(focus, mode, minutes)
  Lower: squat, hinge, single_leg | knee_ext, knee_flex, calf
  Upper: h_push, v_pull, incline | v_push, h_pull, lateral_raise, arms
  Full:  squat | single_leg, h_push | incline, v_pull | h_pull, hinge | hip_thrust, 1–2 изоляции

// 5. Заполнение слотов (по убыванию Σneed слота)
for slot:
  if slot.main ∧ anchor[gym][slot.pattern] ∈ pool → взять якорь
  else → argmax score(e), e ∈ pool ∩ slot.patterns

// 6–10
sets = distributeSets(...)       // load-and-progression §1: недобор недели / оставшиеся тренировки, 2–4 на упражнение
fitTime(); order(); pairSupersets(); addWarmups(); assignLoads(); explain()
assertHardLimits()               // safety.md §6: при нарушении урезать
```

**Оценка упражнения**
```
score(e) = 3.0 · Σ_m e.muscles[m] · needNorm[m]
         + 1.5 · hasHistory(e, 8 нед; тренажёр/блок — в этом зале)
         + 1.0 · pref(e)                                 // −1…+1
         + 0.6 · [lengthBias = long ∧ цель ≠ сила]       // растяжение под нагрузкой [Maeo 2021/2023; Pedrosa 2022]
         + 0.5 · fitExp(e)                               // новичку stability 1–2; опытному свободные веса ок
         − 0.5 · [зона «иногда беспокоит» ∧ contraindication modify]
         − 2.0 · overlap(e, chosen)                      // тот же vectorKey → исключить; та же главная мышца + паттерн → −2
         − 0.8 · fatigueOverBudget(e)                    // бюджет Σfatigue за сессию ≈ 10 (новичок 8)
         − 0.4 · [аксессуар был в прошлой однотипной сессии ∧ есть альтернатива]
         + 0.01 · rng()
Жёстко: axial ≥ moderate ≤ 2 (режимы → 1); новичку тяжёлые присед и становая не в один день;
        мышца с R < 0.5 и вкладом ≥ 0.5 → упражнение исключено.
```
Веса score — стартовые, в конфиге.

## 3. Якоря и разнообразие
- **Якорь** = основное упражнение главного паттерна шаблона, в зале, на мезоцикл. Хранится `anchor[gymId][pattern]`.
- Выбирается в начале мезоцикла: лучшее по score, с перевесом истории и стабильности.
  У новичка якоря фиксируются **в конце первой недели**, а не на первой тренировке.
- Меняется внутри мезоцикла только по причине: замена пользователем (см. предпочтения), травма/ограничение, нет оборудования.
- **Дополняющие**: на каждый слот на мезоцикл — пара вариантов A/B, чередуются по сессиям
  (каждый должен встретиться 3–4 раза за цикл, иначе прогрессию не увидеть). Новый мезоцикл меняет один из пары.

## 4. Замена («тренажёр занят» / «не хочу»)
```
sim(x, y) = 0.45·cos(muscles) + 0.2·[тот же pattern] + 0.1·[тот же lengthBias]
          + 0.15·hasHistory(y) + 0.1·[setupSec ≤ 60] − 0.3·max(0, y.skill − allowed)
```
Показать топ-3 из пула (с учётом safety). Занятое оборудование помечено busy до конца сессии.
Вес для замены — по [load-and-progression §5](load-and-progression.md). Якорь возвращается в следующей сессии
(если это не повторяющаяся замена, см. §8).

## 5. Порядок
Ключ сортировки: `(tier, −приоритетная_мышца, −skill, −fatigue, bilateral раньше unilateral, id)`
- tier 0 — осевые или skill 3; tier 1 — прочие базовые; tier 2 — тренажёрные и односторонние базовые;
  tier 3 — изоляция; tier 4 — пресс и икры.
- Первое упражнение приоритетной мышцы поднимается в начало своего tier.
- Мышцы, которые пользователь часто пропускает в конце (§8), ставятся раньше.

## 6. Время
- Работа: повторы × 3.5 с; одностороннее ×2 + 15 с.
- Отдых — [load-and-progression §6](load-and-progression.md).
- Переход: `setupSec` (штанга с блинами ≈ 2–2.5 мин).
- Разминка: ~4 мин перед первым базовым, ~2 мин перед каждым новым паттерном.
- Накладные расходы на сессию: 3 мин.

**fitTime**, если оценка больше бюджета (по порядку): суперсеты (если разрешены) → изоляция с низкой потребностью до 2 подходов →
убрать изоляцию с низкой потребностью → базовые 4 → 3 подхода. Якоря и базовые не удаляем, минимум 2 подхода.
Если остаётся > 8 мин — +1 подход мышце с наибольшей потребностью (в лимитах) или изоляция.
Недобор недели добирается частотой, а не раздуванием одной тренировки.

## 7. Суперсеты (экономия ~30–40% времени при том же объёме [Robbins 2010; Weakley 2017])
- Разрешены: антагонисты (h_push + h_pull, v_push + v_pull, бицепс + трицепс) и «не конкурирующие» (изоляция ног + изоляция верха).
- Условия: одна станция или соседние (гантели + скамья, блочная рама); оба `supersetOk`.
- Запрещены: axial ≥ moderate, skill 3, тяжёлый якорь со штангой (≤ 6 повторов), общие мышцы с вкладом ≥ 0.5
  (тяга + сгибания), первые 4 сессии новичка, режимы `cautious` / 65+ / беременность.
- Отдых A → B 60–90 с. Настройка: «авто, если не хватает времени» (по умолч.) / всегда / никогда.

## 8. Предпочтения и обучение на поведении
`pref[exerciseId]` с затуханием 90 дней: замена −0.3, пропуск −0.2, ручное добавление +0.3.
- 2 замены X → Y за 30 дней → X получает −1.
- 3 замены → X больше не предлагается, Y становится якорем (код `PREF`).
- Кнопка «Не предлагать это упражнение» → pref = −∞ (отменяется в каталоге).

**Пропуск мышцы** (например, ноги пропущены 3 раза): долг ≤ 1.5 × цель; после 2-го пропуска — ноги раньше в сессии
и варианты с низким fatigue; после 3-го — один вопрос: «нет времени / не нравится / болит / тренирую отдельно»:
время → короче блок; болит → safety (зона + степень); отдельно → ноги на поддержке и вне баланса.

## 9. Объяснимость — коды причин
В `WorkoutExercise` хранится список **кодов с параметрами** (не готовый текст) + `engineVersion`.
Каждое слагаемое score и каждое жёсткое правило оставляет код; в интерфейсе — 1–2 главных.

| Код | Текст |
|---|---|
| `ANCHOR{week, of}` | Основное упражнение цикла — неделя 3 из 6, следим за прогрессом |
| `NEED{m, done, target}` | Задней поверхности бедра не хватает: 4 из 12 подходов за неделю |
| `BALANCE{pull}` | Тяг меньше, чем жимов — выравниваем |
| `STRETCH` | Нагружает мышцу в растянутом положении — так она растёт лучше |
| `HISTORY{w}` | Знаем твой рабочий вес: 40 кг |
| `PROGRESS{from, to}` | В прошлый раз 3×12 — добавляем вес: 40 → 42.5 кг |
| `RETURN{weeks}` | После 5 недель перерыва — легче, вернёмся за 2–3 тренировки |
| `SAFE_ALT{zone}` | Вариант, бережный к плечу |
| `SUB_BUSY{from}` | Замена: тренажёр занят |
| `PREF{from}` | Ты обычно меняешь X на это |
| `TIME_CUT` | Сократили изоляцию, чтобы уложиться в 30 мин |
| `DELOAD` | Разгрузочная неделя — легче, чтобы дальше расти |
Тексты без медицинских утверждений. Тест: снимок результата и кодов при фиксированном входе.

## 10. Крайние случаи
- **Только гантели**: гоблет-присед, болгарские выпады, румынская с гантелями, тяга одной рукой (широчайшие 0.75), жимы, махи.
  Мышцы без упражнения с вкладом ≥ 0.5 → `reach = false`, долг не копится; подсказка в настройках зала («Добавь турник — для широчайших»).
  Лёгкие гантели → односторонние варианты, упражнения в растяжении, диапазон до 20–30 повторов.
- **Нет оборудования для ног**: сплит-присед, зашагивания, румынская на одной ноге, ягодичный мостик, икры на ступеньке
  (нордические — только опытным). Иначе ноги `reach = false` + баннер «В этом зале ноги не тренируются».
- **30 минут**: 4 упражнения — 2 базовых + пара изоляции суперсетом; 2–3 подхода; разминка только перед первым базовым;
  `setupSec ≤ 60`; фокус на 2–3 мышцах с наибольшей потребностью.
- **Первая тренировка**: готовность у всех 1; новичку «всё тело»; stability ≤ 2, skill ≤ 2; 5–6 упражнений по 2 подхода, RIR 3–4;
  пристрелка весов; якоря не фиксируются.
- **Несколько залов**: якоря — по залу; рабочий вес тренажёров и блоков — по ключу `(exerciseId, gymId)` (стеки несравнимы),
  штанга и гантели — общий. В новом зале нет якоря → ближайшее по sim с историей. Объём и готовность общие.
- **Своё упражнение**: при создании 3 обязательных шага — паттерн, главная мышца (карта тела), оборудование.
  Вторичные мышцы подставляются из шаблона паттерна (`dataSource = inferred`), можно править.
  Без этих данных упражнение можно добавить только вручную; автоматически не подбирается.
- **Всё оборудование занято / пул пуст по слоту**: слот пропускается, недобор → долг; если пусто > половины слотов —
  сообщить и предложить «короткую тренировку» из доступного.
