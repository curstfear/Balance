Каталог — фундамент качества тренировок. Черновик разметки готовит Claude, владелец проверяет.

## Паттерны
`h_push, incline_push, v_push, chest_fly, h_pull, v_pull, shoulder_ext, lateral_raise, rear_delt, shrug,
squat, hinge, hip_thrust, single_leg, knee_ext, knee_flex, hip_add, hip_abd, calf, elbow_flex, elbow_ext,
core_flex, core_anti_ext, core_anti_rot, carry`

Семейства для баланса: **push** (h_push, incline_push, v_push, chest_fly, elbow_ext) ·
**pull** (h_pull, v_pull, shoulder_ext, rear_delt, shrug, elbow_flex) · **quad** (squat, single_leg, knee_ext) ·
**posterior** (hinge, hip_thrust, knee_flex) · **core**.

## Каталог в коде
- Данные — `src/data/catalog/`: `muscles.ts` (мышцы, группы цвета, паттерны, зоны), `equipment.ts`, `exercises/*.ts`
  (push, pull, legs, arms, core), общий модуль `index.ts`. Только данные и чистые функции, без UI и IndexedDB.
- `CATALOG_VERSION` растёт при любом изменении разметки.
- **id упражнения не удаляется и не переиспользуется.** Все выпущенные id перечислены в `released-ids.json`;
  переименование — через `RENAMED` (старый → новый). Тест не даст удалить id.
- Автопроверка — `catalog.test.ts`: ссылки, доли мышц, ровно одна главная мышца, 2–3 подсказки по правилам текстов,
  противопоказания, страховка, шаг веса, покрытие (у каждого паттерна ≥ 2 упражнений, каждая мышца нагружается
  с долей ≥ 0,5 минимум в 3 упражнениях, в зале «только гантели» доступны все крупные мышцы), каждое оборудование используется.

### Правила разметки
- `supersetOk = false`, если `axial ≥ moderate` **или** `skill = 3` (selection §7).
- `needsSafety` — только штанга: жим лёжа и под углом на скамье, присед со штангой на спине или груди.
- Новичку (`minExperience = novice`) не даются упражнения со `skill = 3`.
- Каждое упражнение с `axial = high` имеет противопоказание по зоне «поясница».

### Шаг веса по умолчанию
| equipClass | Верх тела | Низ тела |
|---|---|---|
| штанга, Смит, рычажный тренажёр | 2,5 кг | 5 кг |
| гантели | 2 кг | 2 кг |
| гиря | 4 кг | 4 кг |
| блок | 2,5 кг | 2,5 кг |
| тренажёр со стеком | 5 кг | 5 кг |
| собственный вес | прогрессия повторами | — |
| с отягощением / в гравитроне | 2,5 / 5 кг | — |
Точный шаг задаётся залом пользователя (этап 4); в упражнении можно переопределить `weightStep`.

## Изображения
Решение владельца (этап 2): вариант «Крупный план» — свои рисунки не используются.
- **Что работает** — увеличенный фрагмент анатомического атласа вокруг главной мышцы; рабочие мышцы закрашены
  цветом своей группы (основная — ярко, с долей ≥ 0,5 — бледнее). Обрезка по главной мышце — `src/ui/art/art.ts`.
- **Как выполнять** — два кадра Everkinetic: начальное и конечное положение (`technique.art = {id, first}`).
  Линии рисунка красятся цветом темы (маска), белый фон рисунка удалён.
- Источники и лицензии (показаны в приложении: Профиль → «Источники изображений»):
  Everkinetic — CC BY-SA 4.0; атлас «Muscular system» (Termininja, Wikimedia Commons) — CC BY-SA 3.0;
  слои мышц — проект wger (CC BY-SA). Средняя и задняя дельта, предплечья, приводящие и внутренняя часть
  бицепса бедра дорисованы поверх атласа для Balance. Изменения распространяются под той же лицензией.
- Сборка: `node scripts/build-art.mjs <everkinetic dist/svg> <wger images/muscles>` → `public/art/` и
  `src/ui/art/overlays.ts`. Запускать после изменения `art` в каталоге.
- Все изображения входят в офлайн-кэш приложения.
