## Главные принципы
1. **Сначала не навредить.** Порядок приоритетов при любом конфликте правил:
   **безопасность и жёсткие лимиты → ограничения пользователя → восстановление → потребность мышц → баланс → предпочтения → разнообразие.**
   Правило ниже по списку никогда не отменяет правило выше.
2. **Прогресс измерим.** Основные упражнения («якоря») не меняются весь мезоцикл (4–8 нед), иначе рост веса не отследить.
   «Каждый раз новая тренировка» = каждый раз заново подобраны мышцы, объём и веса, а не случайные упражнения.
3. **Медленно разгоняемся, быстро тормозим.** Рост нагрузки ограничен процентами; снижение при боли, усталости, регрессе — сразу.
4. **Новичок — отдельный режим** первые 8–12 недель: проще упражнения, дальше от отказа, плавный разгон объёма.
5. **Не верим цифрам слепо.** Люди занижают «сколько ещё мог» (RIR) примерно на 1 повтор — движок это корректирует.
6. **Объяснимость.** Каждое решение оставляет код причины → пользователь видит «почему».
7. **Детерминизм.** Одинаковый вход → одинаковая тренировка (seeded rng только для равных вариантов). Это позволяет тестировать.
8. **Все числа в конфиге.** Большая часть констант — консервативная практика, а не измерения; их подстраиваем по реальной истории.

## Конвейер: от «Начать тренировку» до сохранения

```
Профиль + опрос здоровья + ограничения
Зал (оборудование, страховка) + история + чек-ин + время
        │
1. Допуск         safety: блок/осторожный режим, красные флаги, закрытые зоны      → safety.md
2. Контекст       перерыв? мезоцикл/разгрузка? режим новичка? смещение RIR         → load-and-progression.md
3. Состояние      недельный объём по мышцам, готовность (усталость), баланс 30 дн  → load-and-progression.md
4. Сборка         пул упражнений → фокус → слоты → якоря/подбор → подходы →
                  время → порядок → суперсеты → разминка → «почему»                → exercise-selection.md
5. Назначение     вес, повторы, целевой RIR на каждый подход                       → load-and-progression.md
6. Проверка       финальный проход по жёстким лимитам (если нарушено — урезать)    → safety.md
        │
Живая тренировка: после каждого подхода — повторы, вес, RIR, (боль) →
подстройка следующего подхода в лимитах; замены; досрочное сокращение
        │
Сохранение сырых фактов → обновление смещения RIR, предпочтений, e1RM (вычисляемо)
```

## Глоссарий
- **Рабочий подход** — подход с RIR ≤ 4 (после поправки на смещение). Разминочные не считаются.
- **RIR** (reps in reserve) — сколько ещё повторов мог сделать. В интерфейсе: кнопки, без термина.
- **Дробный подход** — подход засчитывается мышце с весом её вклада (1 / 0.75 / 0.5; 0.25 — только в усталость).
- **e1RM** — расчётный максимум на 1 повтор (формула Эпли, только по подходам ≤ 12 повторов до отказа).
- **Готовность** — 0–1, насколько мышца восстановилась от накопленной усталости.
- **Якорь** — основное упражнение на паттерн в данном зале на мезоцикл.
- **Мезоцикл** — блок 5–8 недель, после него разгрузка.
- **Паттерн** — тип движения (горизонтальный жим, вертикальная тяга, присед, наклон…).
